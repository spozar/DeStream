# Project
DeStream — native multiplatform streaming client (SwiftUI, macOS 14+ and iOS 18+) using the Stremio addon protocol.
Full plan: PLAN.md. Tick tasks off in PLAN.md when done.

# Rules
- Swift 6 (strict concurrency), SwiftUI, async/await, Codable. No third-party deps except MPVKit (LGPL product "MPVKit").
- One multiplatform target (`DeStream`), generated by XcodeGen from `project.yml` — never hand-edit the .xcodeproj; run `xcodegen generate` after adding/removing files (scripts/build.sh does it).
- Core/ has no UI and avoids #if os(); platform code lives in Platform/.
- Every change must build for both macOS and iOS.
- Keep code clean; only comment where something is genuinely non-obvious.
- Never commit or push unless explicitly asked.
- Addon manifest URLs contain secrets (TorBox key inside Comet URL): Keychain only, never log or hardcode them; use `Addon.redact`.
- Library paths in meta.json are relative to the title folder, never absolute.
- Tests use JSON fixtures in Tests/Fixtures (bundled as a folder resource; load with `Bundle(for:).url(forResource: "Fixtures/<name>", withExtension: "json")`).

# Architecture contracts
- `AppServices` (Core/AppServices.swift) owns all singletons; each is also injected individually via `.environment(...)` (read with `@Environment(AddonRegistry.self)` etc.).
- Navigation: push `Route` values (Features/Shell/Routes.swift); start playback with `@Environment(\.play)` + `PlaybackRequest`.
- Public signatures in the stubbed files are contracts other agents depend on. You may ADD API freely; changing/removing an existing signature requires updating all call sites.

# Build (each agent passes its own name so DerivedData doesn't collide)
scripts/build.sh <name> mac|ios|test|all
scripts/install-iphone.sh — build, install and launch on the paired iPhone.

# Signing
- Debug builds use automatic signing with the iCloud key-value entitlement (syncs Suggestions choices); this Mac and the iPhone are registered on team 99476Z45K6.
- Hardened runtime is on for Release only (Debug off so the ad-hoc-signed test bundle can load).

# Releasing the macOS app (public repo github.com/spozar/DeStream, not the App Store)
- Normal path: bump `MARKETING_VERSION` (and `CURRENT_PROJECT_VERSION`) in project.yml and push to main; `.github/workflows/release.yml` builds, notarizes and publishes `v<version>` with the .dmg and .zip on this repo's Releases. See RELEASING.md.
Local build:
1. Bump `MARKETING_VERSION` (and `CURRENT_PROJECT_VERSION`) in project.yml.
2. `NOTARY_PROFILE=notary scripts/dmg-mac.sh` — archives, signs with "Developer ID Application: Mediaempire Group AB" (login keychain), drops the iCloud entitlement (it would need a Developer ID provisioning profile), builds `dist/DeStream-<version>.zip` and `.dmg`, notarizes and staples both.
3. The `notary` notarytool keychain profile is already saved; never ask for or handle the password. If it's missing, the user recreates it with `xcrun notarytool store-credentials notary --apple-id <their Apple ID> --team-id 99476Z45K6`.
4. Ask before submitting for notarization. After a build, play a stream with mpv in the exported app: it runs under hardened runtime, and LuaJIT may need `com.apple.security.cs.allow-jit` if playback crashes.
- `ITSAppUsesNonExemptEncryption` is NO: the app only uses standard HTTPS/TLS and the system Keychain. Revisit if it ever adds its own encryption.
